# 0001. База локальной macOS-сборки MVP

**Статус** — принято для первого среза, 21 ноября 2026 года.

Варианты для проверки самостоятельного запуска — собственная сборка из исходников Code — OSS и упаковка проверяемого готового дистрибутива. Для первого среза используем ARM64-бандл VSCodium 1.143.17232, основанный на Code — OSS, с закреплённой контрольной суммой релиза. TripleCode задаёт собственное имя, идентификатор, директории данных и URL scheme. Расширение MVP встроено в бандл. Лицензионные уведомления базового дистрибутива сохраняются. Сборка использует ad hoc подпись. [VSCodium 1.143.17232](https://github.com/VSCodium/vscodium/releases/tag/1.143.17232)

Компоновка MVP использует нативную правую боковую область Workbench и патч начальных размеров, привязанный к SHA базового дистрибутива. Сборка проверяет совпадение ожидаемых точек изменения и пересчитывает контрольные суммы. Верхняя панель регистрирует действия TripleCode в штатном меню Workbench. Иконки оболочки из Figma упакованы локально, а оформление вкладок и строки состояния применяется на уровне Workbench. Пересмотрим выбор основы при следующем обновлении upstream или при переходе к публичному распространению.

## Приёмка

На macOS arm64 проверили подпись и встроенный launcher. В отдельном профиле открыли Welcome, выбрали локальную папку, открыли исходник в Workspace, отправили запрос в Agent и получили штатный diff. Discard сохранил исходное содержимое файла. Apply и Save записали предложенный комментарий на диск. Проверка проходила внутри TripleCode.app через локальную автоматизацию интерфейса.

При проверке интерфейса агент был отдельным правым представлением. Терминал располагался под редактором и не заходил под правую панель. Preview показывал изменение в правой панели, а действие Review открывало штатный diff в редакторе.

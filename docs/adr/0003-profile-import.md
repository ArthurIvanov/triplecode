# 0003. Импорт профилей для MVP

**Статус** — принято для MVP, 22 ноября 2026 года.

## Контекст

TripleCode должен поддерживать миграцию из VS Code для первого сегмента пилота (разработчики с существующими VS Code настройками). Требования по ide-design.md:
- Действие «Импортировать из VS Code» в Settings без входа в аккаунт
- Предпросмотр настроек, клавиш, сниппетов, тем и расширений
- Откат импорта
- Если VS Code не найден — предложить штатный импорт файла через Profiles

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Штатный Profiles API | Предпросмотр и откат уже реализованы, минимальные изменения | Требует локальной установки VS Code для one-click import |
| Прямое чтение файлов конфигурации | Полный контроль, не зависит от Profiles API | Требует reimplement предпросмотр и откат, сложнее поддерживать |
| Копирование папки профиля | Полная миграция (как Cursor workaround) | Хрупко, нарушает инкапсуляцию, проблематично для отката |

## Решение

Использовать **штатный Profiles API** для MVP:
- One-click import из локальной установки VS Code через команду `triplecode.importFromVSCode`
- Чтение `settings.json`, `extensions/` и `state.vscdb` из локальной установки
- Предпросмотр через webview с выбором категорий
- Создание нового профиля через ProfileService
- Откат через удаление профиля и восстановление предыдущего
- Fallback на штатный `Profiles: Import Profile` если VS Code не найден

## Реализация MVP

### Команды
- `triplecode.importFromVSCode` — импорт из локальной установки
- `triplecode.rollbackImport` — откат импорта

### Содержимое импорта
- Settings (настройки)
- Keyboard Shortcuts (клавиши)
- User Snippets (сниппеты)
- Tasks (задачи)
- Extensions (расширения) из Open VSX

### Ограничения MVP
- Только один профиль для импорта
- Расширения только из Open VSX
- Нет проверки лицензий расширений
- Нет облачного синка

## Последствия

### Положительные
- Минимальные изменения в коде (использование upstream API)
- Предпросмотр и откат уже реализованы в Workbench
- Знакомый UX для пользователей VS Code

### Отрицательные
- Требует локальной установки VS Code для one-click import
- Не все расширения доступны в Open VSX
- Возможны конфликты при импорте

## Условия расширения

Для беты:
- Проверка лицензий расширений
- Поддержка нескольких профилей
- Облачный синк через TripleCode аккаунт
- Проверка совместимости расширений
- Кэширование метаданных расширений
